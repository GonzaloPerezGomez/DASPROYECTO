3WORK MANAGER
WorkManager es una API incorporada en el API 28 para 
gestionar tareas programables ( persistent work : se 
mantiene programado a pesar de reinicios de la app o del 
sistema )
Para APIs menores, WorkManager usa por debajo:
JobScheduler (para API >= 23)
Custom AlarmManager + BroadcastReceiver (para lograr 
compatibilidad con API 14 -22)
Permite lanzar tareas:
De única ejecución
De ejecución repetitiva
Larga ejecución (más de 10 minutos)
Programable a posteriori ( Deferrable )

                .build();Incrementar el tiempo entre

20DOWNLOAD MANAGER
Se puede establecer un BroadcastReceiver  para

BroadcastReceiver descargaReceiver = new BroadcastReceiver () {
    @Override
    public  void onReceive( Context context, Intent  intent) {
        long id = intent.getLongExtra( DownloadManager. EXTRA_DOWNLOAD_ID, - 1);
        if (descargaId  == id) {
            Toast. makeText (MainActivity. this, “¡Descarga completada!",  
         Toast.LENGTH_SHORT ).show();
        }
    }};-------------------------------------------------------//En el onCreate  de la Actividad:
registerReceiver (descargaReceiver, new IntentFilter (DownloadManager.ACTION_DOWNLOAD_COMPLETE));
//En el onDestroy de la Actividad:
unregisterReceiver( descargarReceiver)

23ALARMAS
Alarmas
Para programar una alarma se usa el AlarmManager  del 
sistema
Las alarmas pueden tener distintos comportamientos
ELAPSED_REALTIME: no despierta el dispositivo y lanza la alarma en 
base al tiempo que ha transcurrido desde que el dispositivo se arrancó
ELAPSED_REALTIME_WAKEUP: similar al anterior, pero despierta el dispositivo
RTC: lanza la alarma a la hora especificada, pero no despierta el dispositivo
RTC_WAKEUP: lanza la alarma a la hora especificada despertando el dispositivo
